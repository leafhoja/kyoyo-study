# 05_章構成一覧

## 1. この文書の目的

サイト全体の章構成を確定させる。`01_全体基本設計.md` §5.7〜5.8で示した暫定の大枠を、公式試験情報（`00_調査結果.md`）に基づいて具体化し、章ごとの目的・前提知識・推奨順序・Level0導入の要否を一覧化する。個々の章の詳細（節構成・練習問題との接続等）は `chapters/` 配下の章別詳細設計書に委ねる。

## 2. 対象範囲

全章の一覧、章構成の設計軸、推奨学習順序、章間の前提関係、各章のLevel0導入要否の判断。

## 3. 前提

`00_調査結果.md` §4.1（試験構成・配点比率）、`01_全体基本設計.md` §5.3（合格に必要な能力の整理）・§5.7（情報アーキテクチャ大枠）を前提とする。

## 4. 設計方針（章構成の軸）

プロジェクト仕様書5節が求める「試験段階別・出題形式別・能力別・分野別・学習段階別・インプットとアウトプット・時間制約・思考過程・解答作成技術・実戦演習・振り返り」という観点を、次のように組み合わせる：

- **大枠（部）＝試験段階＋出題形式**：第1次試験（基礎能力試験・総合論文）と第2次試験（企画提案・政策課題討議・人物試験）という試験段階を軸に部を分け、部の中で出題形式ごとにさらに分ける。
- **部の中（章）＝能力・分野**：基礎能力試験対策は「知能分野」（文章理解・判断推理・数的推理・資料解釈）と「知識分野」（自然科学・人文科学・社会科学・時事）という能力・分野の軸で章を分ける。
- **各章の内部＝学習段階（インプット→アウトプット→振り返り）**：追加事項Bの段階構造（説明→用語→具体例→考え方→例題→基礎→条件変化→複合→本番近似→過去問）を全章共通の内部構造とする。
- **第7部＝時間制約・振り返りの統合編**：学習計画・過去問活用法・直前期の心構えという、特定の分野に属さない横断的なテーマをまとめる。

### 5.2 推奨学習順序

```
ch0（必須の起点）
→ ch1〜ch4（知能分野。文章理解→判断推理→数的推理→資料解釈の順を基本とするが、
   苦手分野から先に着手することも妨げない）
→ ch5〜ch8（知識分野。並行学習も可）
   ※ ch9・ch10（総合論文）とch11・ch12（企画提案）は、記述力育成に時間がかかるため
     ch1〜ch8と並行して早期から着手することを推奨（01番§5.10・§5.16）
→ ch13（政策課題討議）・ch14（人物試験）は第2次試験直前期でも一定の対応が可能なため、
   優先度はやや低いが、ch0の直後から概要だけ把握しておくことは推奨
→ ch15（学習計画・過去問活用法）は早期に一読し、以後は随時参照
→ ch16（総仕上げ）は各分野が一定水準に達した段階、または直前期に
```

### 5.3 各章の完了条件（大枠）

各章詳細設計書（chapters/）で個別に定めるが、共通の型として次を基本とする：

- 閲覧完了：章本文を最後まで表示したこと
- Level到達：Level 0〜Level 3相当の問題群で一定の自力正解率を満たしたこと（基礎能力試験科目のみ。総合論文・企画提案・討議・人物試験は正誤で測れないため、後述の代替条件を用いる）
- 記述式・面接系科目（ch9・ch10・ch11・ch12・ch13・ch14）の完了条件は、正誤ではなく「思考手順チェックリストを自分の言葉で説明できる」「模擬演習を1回以上実施し振り返りメモを記録した」等の質的な条件とする（詳細はchapters/該当章および09_解答解説設計.md）

### 5.4 各章の到達目標・詳細12項目について

プロジェクト仕様書5節が定める各章共通12項目（目的・位置付け・到達目標・前提知識・学ぶべき知識技能・典型出題形式・解法思考手順・よくある誤り・練習問題への導線・過去問への導線・復習方法・完了判定）は、本一覧表ではなく `chapters/` 配下の章別詳細設計書に、章ごとに記述する。全17章を機械的に同一構造にせず、記述式・面接系の章（ch9〜ch14）は「解法・思考手順」を「思考の型・構成の技術」に、「過去問への導線」を「模擬演習・自己採点観点」に読み替える（プロジェクト仕様書5節「内容に応じて必要な項目を調整」に対応）。

## 7. 章構成の方針転換（2026-07-31）

2026-07-31、市販されている公務員試験対策の参考書と同等以上の網羅性・深度を持たせる方針が確定した。これに伴い、本節が以前記していた「知能分野・知識分野は大枠でまとめ、章内の節で細分化する」という方針を撤回し、下記7-1の分割方針に切り替える。**現行のch0〜ch16という17章構成は、この新方針のもとでは『試験制度の概要（第0部相当）』にとどまる導入レベルの構成と位置づけ直す。** 市販の公務員試験対策本が物理・化学・生物・地学、あるいは判断推理の中の対応関係・順序関係・位置関係・試合形式・真偽問題等をそれぞれ独立した章として扱っているのと同等の粒度まで、本サイトの章構成を細分化する。

### 7-1. 新しい章構成の方針

- **知能分野（ch1〜ch4）は、出題テーマ単位でさらに章を分割する。** 例：判断推理は「命題と論理」「対応関係」「順序関係・位置関係」「試合形式・操作の手順」「真偽問題・暗号・集合」の5章程度に、数的推理は「速さ（旅人算・流水算・通過算・時計算）」「割合・比・濃度算」「場合の数・確率」「図形」「仕事算・方程式の応用」の5章程度に分割する。
- **知識分野（ch5〜ch7）は出題科目そのもの（物理・化学・生物・地学、日本史・世界史・地理・思想・文学芸術、政治・経済・法律・社会）を独立章とする。** これは05番旧版で「初学者には見通しが悪くなる」として退けた方式だが、市販本相当の深度を優先する方針転換により採用する。見通しの悪化は、各分野群の入口に短いオーバービュー（ハブ）ページを置くことで緩和する（7-2参照）。
- **文章理解（ch1）は現代文（要旨把握・内容合致／空所補充・文章整序）と英文で章を分ける。**
- **資料解釈（ch4）は実数・割合の読み取り／増加率・指数／構成比・グラフ種別、で章を分ける。**
- **時事（ch8）は政治・国際時事、経済時事、社会・環境時事、程度の粒度で検討するが、情報の陳腐化が速い分野であるため細分化の優先度は他分野より低くする。**
- ch9〜ch16（総合論文・企画提案・討議・人物試験・学習計画・まとめ）は記述式・面接系であり、当面は現行の粒度を維持する（過度な細分化は演習の一体性を損なうと判断）。

### 7-2. 移行時の互換性方針

- 既存の章ページ（ch1.html〜ch8.html）は削除せず、分割後の各章への短い導入・ハブページとして再構成する（本文の詳細記述は分割後の各章に移し、ハブページには分野の全体像と各章へのリンク一覧を残す）。
- 既存の問題データ（data/questions/ch01.json〜ch08.json）は、既存の`tags`（例：ch05の物理・化学・生物・地学タグ）を手がかりに分割後の各章の問題ファイルへ機械的に再配分する。
- chapterId・ファイル名は「ch5-1」のように親章番号を保持したハイフン付き連番とする（history.js・quiz.jsのchapterIdは自由文字列として扱われるため、この形式変更によるコード側の修正は不要）。
- 部（第1部〜第7部）の対応関係、ナビゲーション（index.html・kyoyo.js の NAV_PARTS）、検索索引は、分割の進行に合わせて都度更新する。

### 7-3. 旧版で採用しなかった案（2026-07-31以前の記録として保持）

- ch1〜ch4（知能分野）をさらに細分化する案：初学者にとって章数が増えすぎ迷いやすくなるため採用せず、章内の節構成で対応する、としていた。→ 7-1の方針転換により撤回。
- 知識分野（ch5〜ch7）を出題科目細分（物理・化学・生物…）ごとに独立章とする案：初学者には見通しが悪くなるため、まず3分野の大枠で章立てし、章内の節でさらに細分化する方式を採用していた。→ 7-1の方針転換により撤回。
