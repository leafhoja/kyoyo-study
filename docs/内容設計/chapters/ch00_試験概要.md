## 1. この文書の目的

サイト全体の起点となる第0章の実装レベル詳細設計を定める。`chapters/00_試験概要_詳細設計.md`（旧版）の内容を土台に、実際の節見出し・box配置・問題文サンプルまで踏み込んで具体化する。

## 3. 前提

`../00_調査結果.md`§4、`../01_全体基本設計.md`§4.13・§5.16、`../05_章構成一覧.md`のch0行、追加事項Bの10項目、`../03_学習体験設計.md`§5.6の誤解リストを前提とする。

## 4. 章の到達目標・位置付け

- **目的**：完全な初学者が、試験の全体像とサイトの使い方を理解し、安心して第1部以降の学習に進める状態を作る。
- **試験における位置付け**：どの試験科目にも直接対応しない、学習の出発点。
- **到達目標**：①試験制度の大枠を自分の言葉で説明できる、②サイト内の推奨学習順序と各章の完了条件の考え方を理解している、③よくある誤解を認識している。
- **前提知識**：なし。

### 5.2 節0.1「この試験で何が問われるのか」（制度説明パート・詳細内容案）

- **0.1.1**：総合職試験＝院卒者試験／大卒程度試験の別、教養区分＝大卒程度試験の一区分で専門試験を課さない、という位置づけをまず図示する。
- **0.1.2**：「専門試験がない＝簡単」ではなく、総合論文・企画提案・討議・人物試験という別の負荷が高い試験がある、という逆説を導入の切り口にする（追加事項Bの「逸話・逆説から入る」を制度説明にも一部適用）。
- **0.1.3**：試験全体の流れをテキストベースの矢印図で示す（`第1次試験（10月頃）→ 第1次合格発表 → 第2次試験（11月頃）→ 最終合格発表（12月頃）→ 官庁訪問（12月中旬〜）`。すべて「年度により変わる」と明記）。
- **0.1.4**：5試験一覧表（試験名・試験段階・配点・測る力を1行ずつ）。

### 5.3 節0.2「合格までのプロセス」（制度説明パート・詳細内容案）

- **0.2.1**：第1次試験合格は基礎能力試験の成績のみで決まり、総合論文は最終合格判定時に合算される、という事実を強調（誤解2「基礎能力試験さえ突破すればよい」への直接的な反証として機能させる）。
- **0.2.2**：最終合格者は「採用候補者名簿」に得点順で記載されるだけであり、採用が確定するわけではない、という段階の違いを図解する。
- **0.2.3**：官庁訪問の特例的な時期（教養区分合格者は例年12月中旬頃開始）を紹介しつつ、詳細は本サイトの対象外であり公式情報を参照する旨を明記する（`01_全体基本設計.md`§5.5「サイトが担わない役割」）。

### 5.4 節0.3「このサイトでの学習の始め方」（対策上の示唆パート・詳細内容案）

- **0.3.1**：「思考の道具（第1部）→知識の土台（第2部）→書く力（第3・4部）→話す力（第5・6部）」の順序イメージ図。
- **0.3.2**：最初の一週間の過ごし方の具体例（例：1〜2日目はch0を読み終える、3日目以降はch1のLevel0〜1に着手、総合論文（ch9）は週1回のペースで並行して触れ始める、等の**例示**。断定的なスケジュールではなく一例として示す）。
- **0.3.3**：過去問は基礎固め（Level0〜3）の後に取り組むものであり、最初から解いて「難しすぎる」と挫折しないための注意。
- **0.3.4**：ヒント→解説→前提章、という対処の流れを紹介（`03_学習体験設計.md`§5.3）。
- **0.3.5**：学習履歴ダッシュボードで「要復習」に自動的に入る仕組みを紹介。

### 5.5 節0.4「よくある誤解」（詳細文面案）

| # | 誤解 | なぜ誤解しやすいか | 正しい理解 |
|---|---|---|---|
| 1 | 教養区分は専門試験がないから簡単 | 「専門試験なし」という言葉だけが独り歩きしやすい | 総合論文・企画提案・討議・人物試験という、正誤が一意でない負荷の高い試験がある |
| 2 | 総合論文試験は学校の小論文と同じ | 「論文」という言葉から学校で書いた小論文を連想する | 教養・哲学的な考え方を問う特有の出題であり、書き方も評価観点も異なる（`ch09_総合論文とは何か.md`参照） |
| 3 | 基礎能力試験さえ突破すればよい | 「第1次試験合格＝基礎能力試験の成績のみ」という制度から誤って一般化しやすい | 総合論文は最終合格判定に合算されるため、第1次試験の段階から総合論文対策も必要 |
| 4 | 過去問を早く大量に解けば合格できる | 「過去問演習が王道」という一般的な受験対策のイメージ | 基礎（Level0〜3）を固めてから過去問（Level4〜5相当）に進む方が効率的（追加事項B） |
| 5 | 一度解けた問題はもう見なくてよい | 「解けた＝習得した」という直感 | 偶然正解やケアレスミスの可能性があり、学習履歴の自己評価・復習対象登録の仕組みがあるのはそのため |

### 5.6 Level0確認問題（章末・問題文サンプル）

1. 「教養区分の第1次試験で課される試験を2つ選びなさい」（多肢選択：基礎能力試験／総合論文試験／企画提案試験／人物試験 → 正解：基礎能力試験・総合論文試験）
2. 「教養区分合格者の官庁訪問は、他の区分と同じ時期に始まる」（正誤問題 → 正解：誤り）
3. 「教養区分の第1次試験合格は、総合論文試験の成績も含めて判定される」（正誤問題 → 正解：誤り。基礎能力試験の成績のみ）

ヒントは常時表示（追加事項CのLevel0原則）。正解より形式慣れを重視する旨を問題画面上部に明記する。

### 5.7 用語集エントリ草案

| 用語 | 定義（草案） |
|---|---|
| 総合職試験 | 中央省庁で政策の企画立案等に従事する職員を採用するための国家公務員試験。院卒者試験と大卒程度試験に分かれる。 |
| 教養区分 | 大卒程度試験の一区分。専門試験を課さず、総合論文試験・企画提案試験等で総合的な判断力・企画力を測る。 |
| 基礎能力試験 | 第1次試験で課される多肢選択式試験。Ⅰ部の知能分野24題＋時事・情報6題と、Ⅱ部の知識分野20題からなる（2026年度）。 |
| 総合論文試験 | 第1次試験で課される記述式試験。教養・哲学的な考え方に基づく総合的判断力・論述力を測る。 |
| 企画提案試験 | 第2次試験で課される、資料を基にした政策提案・プレゼンテーションの試験。 |
| 政策課題討議試験 | 第2次試験で課される、グループ討議形式の試験。 |
| 人物試験 | 第2次試験で課される個別面接。 |
| 官庁訪問 | 最終合格者が採用候補者名簿に記載された後、各府省庁を訪問し採用者が決定されるプロセス。 |
| 採用候補者名簿 | 総合職試験合格者が得点順に記載される名簿（7年間有効）。 |
