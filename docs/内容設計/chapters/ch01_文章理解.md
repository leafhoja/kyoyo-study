# ch01 文章理解

## 1. この文書の目的

第1部第1章「文章理解」の実装レベル詳細設計を定める。`chapters/01_第1部_詳細設計.md`（旧版）ch1部分を土台に、節構成・box配置・問題設計を具体化する。

## 2. 対象範囲

ch1（文章理解）。

## 3. 前提

`../05_章構成一覧.md`のch1行、`../00_調査結果.md`§4.1（基礎能力試験Ⅰ部・知能分野24題中、文章理解10題）、`../07_練習問題設計.md`§5.2を前提とする。

## 4. 章の到達目標・位置付け

- **目的**：現代文・英文の要旨把握・空所補充等の読解技術を身につける。
- **試験における位置付け**：基礎能力試験Ⅰ部・知能分野のうち最大配点（10題／24題）を占める分野。
- **到達目標**：初見の文章から短時間で要旨・論理構造を抽出できる。
- **前提知識**：なし（日本語の読解力は前提とするが、専門知識は不要）。
- **前提章**：ch0。

## 5. 節構成（実装レベル見出し案）

```
h1: 第1章　文章理解
  h2: 1.1 文章理解で何が問われるか
    h3: 1.1.1 出題形式（要旨把握・内容合致・空所補充・文章整序）
    h3: 1.1.2 なぜ「読解力」だけでは足りないのか
  h2: 1.2 基本の考え方：設問を先に読む
  h2: 1.3 解説付き例題（現代文・要旨把握）
  h2: 1.4 確認問題（Level0〜1）
  h2: 1.5 基本問題（Level2）
  h2: 1.6 標準問題（Level3：紛らわしい選択肢）
  h2: 1.7 実戦問題（Level4：時間制限・英文）
  h2: 1.8 高難度・過去問（Level5）
  h2: 1.9 この章のまとめと復習
```

### 5.1 box配置計画

| 節 | box種別 | 内容 |
|---|---|---|
| 1.1.1 | `box-def` | 出題形式4種の定義 |
| 1.1.2 | `box-note` | 「読解力があれば解ける」という誤解への注意（試験特有の時間制約・選択肢の紛らわしさ） |
| 1.2 | `box-thm` | 「設問を先に読む」解法の型 |
| 1.3 | `box-ex` | 解説付き例題（一手ずつ） |
| 1.6 | `box-wrong` | 紛らわしい選択肢のパターン分析 |
| 1.9 | `box-imp` | 章のまとめ |

### 5.2 解説付き例題（1.3）の設計方針

- 題材：3〜4段落程度の平易な現代文（社会・科学系の一般的な話題、著作権に配慮し独自作成）。
- 提示する解法手順：①設問を先に読み「何を聞かれているか」を把握→②段落ごとに一言で要点をメモ→③選択肢を本文と照合→④紛らわしい2択まで絞り込み、根拠となる一文を指差せるか確認。
- 誤答の型を1つ例示（本文の一部だけに合致する選択肢）。

### 5.3 練習問題群の設計（Level別内訳）

| Level | 名称 | 想定問題数目安 | 内容 |
|---|---|---|---|
| 0 | はじめの一歩 | 2〜3問 | 出題形式の確認（「この問題形式は次のうちどれか」等） |
| 1 | 基礎確認 | 4〜6問 | 短文（1段落程度）での要旨把握 |
| 2 | 基本 | 6〜8問 | 標準的な長さの現代文、典型的な出題形式 |
| 3 | 標準 | 6〜8問 | 紛らわしい選択肢を含む現代文 |
| 4 | 実戦 | 4〜6問 | 英文、時間制限付き演習 |
| 5 | 高難度 | 2〜4問＋過去問リンク | 本番相当の複合的な出題 |

（問題数は目安であり、実装フェーズで到達目標に照らして調整する。`../18_未決事項と意思決定記録.md`U-12。）

### 5.4 誤答パターンの詳細

- 本文の一部だけに合致し全体の主旨とはずれる選択肢（最頻出パターン）
- 本文にない一般常識で判断してしまう選択肢
- 因果関係を逆にした選択肢（「AだからB」を「BだからA」とすり替える）

### 5.5 L2深掘りの要否

不要と判断（乱造しない方針、`../02_情報アーキテクチャ設計.md`§5.3）。英文読解の語彙・構文基礎が必要な場合は、L2ではなく1.1節内の補助コラムで対応する。

### 5.6 用語集エントリ草案

| 用語 | 定義（草案） |
|---|---|
| 要旨把握 | 文章全体の主張・結論を捉える出題形式 |
| 内容合致 | 選択肢が本文の内容と一致するかを判定する出題形式 |
| 空所補充 | 文章中の空欄に適切な語句・文を補う出題形式 |
| 文章整序 | バラバラの文・段落を正しい順序に並べ替える出題形式 |
