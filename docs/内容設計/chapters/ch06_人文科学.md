# ch06 人文科学

## 1. この文書の目的

第2部第6章「人文科学」の実装レベル詳細設計を定める。

## 2. 対象範囲

ch6（人文科学）。

## 3. 前提

`../05_章構成一覧.md`のch6行、`../00_調査結果.md`§4.1を前提とする。

## 4. 章の到達目標・位置付け

- **目的**：歴史・地理・思想・文学芸術の基礎知識を確認する。
- **試験における位置付け**：基礎能力試験Ⅱ部・知識分野。
- **到達目標**：主要な歴史的出来事・地理的知識・思想家の主張を関連づけて説明できる。
- **前提知識**：なし。
- **前提章**：ch0。

## 5. 節構成（実装レベル見出し案）

```
h1: 第6章　人文科学
  h2: 6.1 人文科学分野で何が問われるか
  h2: 6.2 歴史（日本史・世界史）の頻出テーマ
  h2: 6.3 地理の頻出テーマ
  h2: 6.4 思想の頻出テーマ
  h2: 6.5 文学芸術の頻出テーマ

  h2: 6.8 高難度・過去問（Level5）
  h2: 6.9 この章のまとめと復習
```

### 5.1 box配置計画

### 5.2 各分野の頻出テーマ（暫定リスト）

- 歴史：日本史の近現代（明治維新以降）、世界史の主要な世界システムの変遷
- 地理：地形・気候の基礎、主要国の産業構造
- 思想：西洋哲学・日本思想の主要な思想家と主張の要点
- 文学芸術：主要な文学作品・芸術運動の時代背景

（実装フェーズで過去問傾向分析を踏まえ優先順位を再確認する）

### 5.3 練習問題群の設計（Level別内訳、4分野合計）

| Level | 名称 | 想定問題数目安 | 内容 |
|---|---|---|---|
| 0 | はじめの一歩 | 4問 | 用語の意味を選ぶだけの一問一答 |
| 1 | 基礎確認 | 8問 | 1事実のみを問う一問一答 |
| 2 | 基本 | 8問 | 典型的な正誤判定 |
| 3 | 標準 | 8問 | 年代整序、複数知識の関連づけ |
| 4 | 実戦 | 4〜6問 | 分野横断 |
| 5 | 高難度 | 2〜4問＋過去問リンク | 本番相当 |

### 5.4 誤答パターンの詳細

- 年代の前後関係の誤り
- 類似人名・地名の混同
- 出来事の因果関係の取り違え

### 5.5 L2深掘りの要否

不要と判断。年表・地図等の視覚補助を本文内に組み込むことで対応する。

### 5.6 用語集エントリ草案

各分野の頻出用語（歴史上の主要な出来事名・思想家名・文学作品名等）を実装フェーズで用語集に順次登録する。
