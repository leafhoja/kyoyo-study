# ch07 社会科学

## 1. この文書の目的

第2部第7章「社会科学」の実装レベル詳細設計を定める。

## 2. 対象範囲

ch7（社会科学）。

## 3. 前提

`../05_章構成一覧.md`のch7行、`../00_調査結果.md`§4.1を前提とする。

## 4. 章の到達目標・位置付け

- **目的**：法律・政治・経済・社会の基礎知識を確認する。
- **試験における位置付け**：基礎能力試験Ⅱ部・知識分野。総合論文（ch9・ch10）の背景知識としても機能する。
- **到達目標**：日本の統治機構・基本的な経済メカニズム・社会制度を説明できる。
- **前提知識**：なし。
- **前提章**：ch0。

## 5. 節構成（実装レベル見出し案）

```
h1: 第7章　社会科学
  h2: 7.1 社会科学分野で何が問われるか
  h2: 7.2 法律（憲法・統治機構）の頻出テーマ
  h2: 7.3 政治の頻出テーマ
  h2: 7.4 経済の頻出テーマ
  h2: 7.5 社会（社会保障等）の頻出テーマ
```

7.9で、本章の知識が総合論文（ch9・ch10）の背景理解に役立つことを明示し、部を越えた接続を作る。

### 5.1 box配置計画

| 節 | box種別 | 内容 |
|---|---|---|
| 7.2〜7.5各節 | `box-def` | 制度・用語の定義 |
| 7.2〜7.5各節 | `box-note` | 類似制度の比較表（誤解防止） |
| 7.9 | `box-imp` | 総合論文との接続の明示 |

### 5.2 各分野の頻出テーマ（暫定リスト）

- 法律：憲法の基本原理、三権分立の仕組み
- 政治：選挙制度、国際政治の基礎枠組み
- 経済：市場メカニズムの基礎、財政・金融政策の基礎
- 社会：社会保障制度の概要、人口動態の基礎

### 5.3 練習問題群の設計（Level別内訳、4分野合計）

| Level | 名称 | 想定問題数目安 | 内容 |
|---|---|---|---|
| 0 | はじめの一歩 | 4問 | 用語の意味を選ぶだけの一問一答 |
| 1 | 基礎確認 | 8問 | 1事実のみを問う一問一答 |
| 2 | 基本 | 8問 | 典型的な正誤判定 |
| 3 | 標準 | 8問 | 制度の比較問題 |
| 4 | 実戦 | 4〜6問 | 分野横断 |
| 5 | 高難度 | 2〜4問＋過去問リンク | 本番相当 |

### 5.4 誤答パターンの詳細

- 類似制度の混同（似た名前の法律・制度の取り違え）
- 政策の目的と手段の混同

### 5.5 L2深掘りの要否

不要と判断。制度比較表（`box-note`）で対応する。

### 5.6 用語集エントリ草案

各分野の頻出用語（統治機構関連用語、市場メカニズム関連用語、社会保障制度名等）を実装フェーズで用語集に順次登録する。
