# ch13 政策課題討議とは何か・討議の型

## 1. この文書の目的

第5部第13章「政策課題討議とは何か・討議の型」の実装レベル詳細設計を定める。

## 2. 対象範囲

ch13（第5部は1章構成）。

## 3. 前提

`../05_章構成一覧.md`のch13行、`../00_調査結果.md`§4.1（政策課題討議試験：約1時間30分、配点4/24）を前提とする。

## 4. 章の到達目標・位置付け

- **目的**：政策課題討議試験の形式・評価される能力を理解し、討議で求められる役割行動を知る。
- **試験における位置付け**：第2次試験。約1時間30分のグループ討議、配点4/24。
- **到達目標**：討議の進行の型を理解し、自分の論点を簡潔に述べ、他者の意見を踏まえて建設的に議論できる。
- **前提知識**：ch0、ch9・ch10（論点整理の技術）。
- **前提章**：ch0（必須）、ch9・ch10（推奨）。

### 5.2 練習・模擬演習の設計（Level別内訳）

| Level | 名称 | 内容 |
|---|---|---|
| 0 | はじめの一歩 | 討議の進行イメージを掴む形式確認 |
| 1 | 基礎確認 | 課題文から論点を1〜2個書き出す一人演習 |
| 2〜3 | 基本〜標準 | 想定される複数の立場（賛成・反対・中間等）を書き出す演習 |
| 4〜5 | 実戦〜高難度 | 一人二役のロールプレイ、可能であれば複数人での模擬討議 |

過去問としての詳細な題材公開は限定的である可能性が高く（`../00_調査結果.md`§4.1）、練習問題での模擬課題を主教材とする（過去問ライブラリへの依存度を下げる設計）。

### 5.3 評価観点チェックリスト（確定版）

- 論点を簡潔に述べられているか
- 他者の意見を要約・接続できているか
- 対立点だけでなく合意形成に貢献しているか
- 時間内にまとめに貢献できたか

### 5.4 誤答（失敗）パターンの詳細

- 自分の意見を長く話しすぎる
- 他者の意見を聞かずに主張を繰り返す
- 対立点ばかり指摘して収束に貢献しない

### 5.5 一人学習での模擬討議方法（案）

一人二役（賛成役・反対役）でのロールプレイ、想定される他者の反論を自分で書き出してから応答を考える練習を案内する。可能であれば模擬討議の相手を探すことも選択肢として提示する（実装フェーズでの検討事項、`../03_学習体験設計.md`と連携）。
