## 4. 章の到達目標・位置付け

- **目的**：自分のペースで学習計画を立て、過去問を効果的に活用する方法を身につける。
- **試験における位置付け**：横断（全試験科目の学習の進め方に関わる）。
- **到達目標**：自分の現在地（学習履歴ダッシュボード）を踏まえ、次に何を優先すべきか判断できる。
- **前提知識**：ch0。
- **前提章**：ch0。本章自体はガイドであり問題演習を持たない。

### 5.2 節15.3「次に何をすべきかの決め方」の内容案

`../01_全体基本設計.md`§5.16の優先順位（①第0章②基礎能力試験③総合論文・企画提案④討議・人物試験⑤予想問題）を、利用者の現在の学習履歴と照らし合わせて具体的にどう判断するかの手順を示す：

```
①学習履歴ダッシュボードで各章の閲覧完了・Level到達状況を確認
②未着手の分野があれば優先順位に従い着手
③要復習問題一覧が一定数を超えていれば復習を優先
④総合論文・企画提案の着手が遅れていないか確認（早期並行着手の推奨）
```

### 5.3 節15.4「過去問はいつ・どう使うか」の内容案

`../06_過去問設計.md`§5.4の方針（Level4〜5相当、基礎固め後）を平易な言葉で再掲し、「過去問を解いて難しいと感じたら、それは基礎固めが足りないサインであり、失敗ではない」という心理的なフォローを加える。

### 5.4 節15.5「よくある計画倒れのパターンと対処」

- 知識分野（暗記）ばかりに時間を使い、記述式・面接系の準備が後回しになる → 早期並行着手の重要性を再掲
- 完璧主義でLevel0〜1に時間をかけすぎる → 各Levelの目的（形式慣れ・基礎確認）を再確認し先に進むことを促す
