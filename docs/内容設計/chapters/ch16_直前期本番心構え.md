# ch16 直前期・本番当日の心構え（総仕上げ）

## 1. この文書の目的

第7部第16章「直前期・本番当日の心構え」の実装レベル詳細設計を定める。既存3サイトの「卒業制作」章の位置付け（`../00_調査結果.md`§3.2⑥）を本章に踏襲する。

## 2. 対象範囲

ch16（第7部・総仕上げ）。

## 3. 前提

`../05_章構成一覧.md`のch16行、`../01_全体基本設計.md`§5.10を前提とする。

## 4. 章の到達目標・位置付け

- **目的**：直前期の過ごし方、本番当日の心構えを整理し、これまでの学習を統合する。
- **試験における位置付け**：横断（全試験段階）。
- **到達目標**：直前期に何を優先すべきか、本番当日に何を意識すべきかを自分の言葉で説明できる。
- **前提知識**：ch0〜ch14の一部完了を推奨。
- **前提章**：ch0（必須）、ch1〜ch14（一部完了を推奨）。

### 5.2 節16.3「本番形式のセット演習」の内容案

`../07_練習問題設計.md`§5.1の「本番形式のセット問題」（基礎能力試験Ⅰ部30題・Ⅱ部20題を模したセット）への導線を提供する。過去問ライブラリの過去問と、練習問題バンクのLevel5相当を組み合わせたセット演習の組み方を案内する。

### 5.3 節16.6「これまでの学習の振り返り（卒業制作）」の内容案

既存3サイトの卒業制作章（人工知能ノートch33、株式ノートch28）の趣旨を踏襲し、利用者が各部の学習を振り返り、自分の弱点・強みを一言でまとめる振り返りを促す構成とする。学習履歴（10番）の記録と接続し、「入学時（ch0を読んだ時点）と比べて何が変わったか」を実感できるようにする。

### 5.4 誤答（誤解）パターンとの接続

直前期に新しい範囲に手を広げすぎる、体調管理を軽視する、という2点を`box-note`で明示的に注意喚起する。
