# 13_データ設計

## 1. この文書の目的

問題データ（過去問・練習問題・予想問題）・学習履歴・用語集のデータ構造を技術的に定める。以下のJSON例はあくまで仕様説明用の最小限の例であり、実装（実データの投入）は行わない（プロジェクト目的§0）。

## 2. 対象範囲

問題データの共通スキーマと種別固有フィールド、学習履歴のスキーマとバージョニング、用語集のスキーマ。

## 3. 前提

`06_過去問設計.md`§5.3、`07_練習問題設計.md`§5.3、`08_予想問題設計.md`§5.1、`10_学習履歴進捗設計.md`の内容をスキーマとして具体化する。`12_技術基本設計.md`§5.6・5.7の概要を詳細化する。

## 4. 設計方針

- 過去問・練習問題・予想問題は共通の基本フィールドを持ち、種別固有の情報は拡張フィールドとして持たせる（共通ロジックでの表示・フィルタを可能にするため）。
- 学習履歴データにはバージョン番号を必ず持たせ、スキーマ変更時も既存データを破棄しない（00_調査結果.md §3.4④、10番§5.7）。
- 問題IDの一意性を保証する命名規則を定める。

## 5. 詳細仕様

### 5.1 問題データ共通スキーマ（例）

```json
{
  "questionId": "Q-CH03-L02-014",
  "type": "practice",
  "field": "数的推理",
  "chapterId": "ch3",
  "difficultyLevel": 2,
  "sequenceOrder": 14,
  "measures": "速さ・時間・距離の基本公式の適用",
  "targetObjective": "CH03-OBJ-02",
  "prerequisiteQuestionIds": ["Q-CH03-L01-003"],
  "prerequisiteChapterIds": ["ch3"],
  "recommendedAfterChapterIds": ["CH-03"],
  "reviewIfWrongGoTo": "ch3#s2",
  "nextQuestionId": "Q-CH03-L02-015",
  "similarQuestionIds": ["Q-CH03-L02-016"],
  "easierQuestionId": "Q-CH03-L01-003",
  "harderQuestionId": "Q-CH03-L03-005",
  "estimatedTimeSeconds": 90,
  "hintStages": 3,
  "typicalWrongAnswers": ["選択肢2：速さと時間を取り違えた誤答"],
  "wrongAnswerCauses": ["公式の分母分子を逆にした"],
  "selfSolveScope": "公式適用の立式まで自力、検算はヒント可",
  "isDiagnostic": false,
  "questionText": "（省略。仕様説明のため実データは記載しない）",
  "choices": ["…", "…", "…", "…", "…"],
  "correctAnswer": 2,
  "explanation": "（省略）",
  "tags": ["速さ", "基本公式"],
  "relatedChapterIds": ["ch3"],
  "relatedQuestionIds": ["Q-CH03-L03-005"]
}
```

`type`フィールドは `"pastExam" | "practice" | "forecast"` のいずれかを取り、§5.2〜5.4の拡張フィールドの要否を切り替える。

### 5.2 過去問（`type: "pastExam"`）の拡張フィールド（例）

```json
{
  "questionId": "Q-PAST-2024A-I-07",
  "type": "pastExam",
  "examYear": "2024年度秋",
  "examStage": "第1次",
  "examSubject": "基礎能力試験Ⅰ部",
  "questionNumber": "問7",
  "copyrightStatus": "urlReferenceOnly",
  "sourceUrl": "https://www.jinji.go.jp/saiyo/siken/mondairei/mondairei_14.html",
  "sourceCheckedDate": "2026-07-30",
  "officialAnswerPublished": true
}
```

`copyrightStatus`は `"officiallyReproducible" | "urlReferenceOnly" | "summaryOnly" | "commentaryOnly"` のいずれかを取り、`06_過去問設計.md`§5.2の4区分に対応する。

### 5.3 練習問題（`type: "practice"`）の拡張フィールド（例）

```json
{
  "practiceCategory": "典型問題",
  "introducesFormat": false
}
```

`practiceCategory`は`07_練習問題設計.md`§5.1の種類一覧のいずれかを取る。

### 5.4 予想問題（`type: "forecast"`）の拡張フィールド（例）

```json
{
  "forecastId": "F-2027A-CH08-003",
  "targetExamYear": "2027年度春（想定）",
  "forecastBasis": ["pastExamTrend", "policyTrend"],
  "basisDescription": "2026年度の年2回実施化に伴う出題範囲の変化を踏まえた予想（00_調査結果.md §4.2参照）",
  "relatedPastExamIds": ["Q-PAST-2024A-II-12"],
  "likelihoodLabel": "中程度",
  "createdDate": "2026-07-30",
  "lastUpdatedDate": "2026-07-30",
  "author": "サイト制作者",
  "reviewStatus": "未レビュー"
}
```

`likelihoodLabel`は`"高い" | "中程度" | "低いが備える価値あり"`の定性的な値のみを許容し、数値的な確率は持たせない（08番§5.3の断定禁止ルール）。`reviewStatus`は`"未レビュー" | "レビュー済み" | "確定版"`を取る（追加事項Aの文書状態管理に対応）。

### 5.5 学習履歴スキーマ（例）

```json
{
  "schemaVersion": 1,
  "questionRecords": {
    "Q-CH03-L02-014": {
      "attempts": 2,
      "correctCount": 1,
      "incorrectCount": 1,
      "lastResult": "correct",
      "lastResultDetail": "understoodCorrect",
      "sawAnswer": true,
      "lastAttemptedAt": "2026-07-29T21:00:00+09:00",
      "flaggedForReview": false,
      "memo": ""
    }
  },
  "chapterProgress": {
    "ch3": {
      "viewedCompleted": true,
      "levelReached": 2,
      "levelStats": {
        "0": { "attempted": 4, "correct": 4, "selfCorrect": 4 },
        "1": { "attempted": 10, "correct": 8, "selfCorrect": 6 },
        "2": { "attempted": 14, "correct": 9, "selfCorrect": 7 }
      }
    }
  },
  "reflectionNotes": {
    "ch9-essay-mock-01": "問いの分解はできたが結論が弱かった"
  }
}
```

`lastResultDetail`は`10_学習履歴進捗設計.md`§5.2の自己評価区分（`understoodCorrect` / `uncertainCorrect` / `luckyCorrect` / `misunderstoodIncorrect` / `carelessMistake` / `timeShortage` / `unanswered` / `sawAnswerOnly`）に対応する値を取る。

### 5.6 用語集スキーマ（例）

```json
{
  "termId": "T-001",
  "term": "判断推理",
  "reading": "はんだんすいり",
  "definition": "与えられた条件から論理的に結論を導く出題分野。",
  "firstAppearedChapterId": "ch2",
  "relatedTermIds": ["T-002"]
}
```

### 5.7 スキーマバージョニング・マイグレーション方針

- 学習履歴データの`schemaVersion`を読み込み時に確認し、現行バージョンと異なる場合は変換関数を適用してから使用する。
- 変換関数は既存フィールドを削除・上書きするのではなく、新フィールドの追加・デフォルト値の補完を基本とする（データの非破壊、00_調査結果.md §3.4④）。
- 問題データ側（過去問・練習問題・予想問題）はGit管理下のファイルであるため、学習履歴のようなマイグレーション機構は不要だが、`questionId`の変更・削除を行う場合は学習履歴側の対応するレコードが孤立しないよう、旧IDから新IDへの対応表を残す運用とする（16_運用更新設計.mdで規定）。

## 6. 他の設計書との関係

`06`〜`08`番の内容項目一覧を本文書のJSONフィールドへ対応させた。`10_学習履歴進捗設計.md`の記録対象・自己評価区分を§5.5のスキーマへ対応させた。`12_技術基本設計.md`§5.6・5.7の概要を本文書で詳細化した。

## 7. 採用しなかった案

- 過去問・練習問題・予想問題を別々の独立したスキーマとして完全に分離する案：共通フィールドが多く、フィルタ・表示ロジックを共通化できなくなるため、共通スキーマ＋`type`による拡張方式を採用した。
- 学習履歴に確率的な「習熟度スコア」のような単一の合成指標を持たせる案：正解率だけで判断しない方針（10番§5.4）と矛盾するため、個別の集計値を保持する方式にとどめた。

## 8. リスクと注意点

- `questionId`の命名規則（章ID・Level・連番を含む形式）は、章の並び替えや問題の追加・削除が発生した際にIDの意味と実体がずれるリスクがある。IDは一度採番したら意味を変更せず、表示上の並び順は別フィールド（`sequenceOrder`）で管理する。

## 9. 未決事項

- 問題データファイルの分割粒度（章単位かLevel単位か）は実装フェーズでファイルサイズを見ながら確定する。
- 学習履歴のIndexedDB移行時のスキーマ差分（12番§9の未決事項と連動）

## 10. 完成条件

問題データ共通スキーマ・種別固有拡張・学習履歴スキーマ・用語集スキーマ・バージョニング方針が、06〜10番の内容と矛盾なく対応していること。
