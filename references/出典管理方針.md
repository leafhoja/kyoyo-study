# 出典管理方針

## 1. この文書の目的

過去問・予想問題・制度説明における出典表示・引用範囲の統一ルールを定める。`06_過去問設計.md`§5.2の著作権区分を運用レベルで具体化する。

## 2. 出典表示の基本ルール

- すべての制度情報・過去問には、出典（資料名・URL）と確認日を明記する。
- 一次資料（人事院公式サイト等）を優先し、二次情報（予備校コラム等）を制度の断定根拠にしない（傾向把握の補助にとどめる、`公式資料一覧.md`§4）。

## 3. 過去問の著作権上の扱い（4区分の運用）

| 区分 | 運用 |
|---|---|
| 公式に掲載・利用可能 | 人事院が「試験問題例」として無償公開しているものに限り、出典明記の上で要約・引用する。全文をそのまま複製しない。 |
| URL参照にとどめる | 問題概要（1〜2文）＋人事院公式PDFへの直接リンク＋独自解説。 |
| 問題の要約のみ掲載 | 出題テーマ・構造のみ紹介し、選択肢の細部は転載しない。 |
| 解説だけを独自に作成 | 問題文を転載せず、類題（練習問題）で代替し、「原文は公式PDFで確認」と明記する。 |

**（2026-07-31改訂）** 本サイトが格納される`国家総合職〈教養区分〉/`フォルダは`.gitignore`対象であり、一度もgitコミット・push実績がない完全ローカル専用フォルダであることを確認した。利用者本人の判断により、個人利用の範囲内では過去問の問題文全文および詳細解説を掲載してよいこととし、上表の「要約・URL参照にとどめる」という制限は個人利用時には適用しない（利用者の明示的な指示による方針転換。2026-07-30時点の初版方針を撤回）。ただし、以下は変わらず維持する：
- 出典（年度・実施回・掲載ページ・確認日）の明記は必須のまま。
- 本文はあくまで人事院公式PDFから実際に取得・書き起こした内容とし、記憶や推測による捏造は行わない（正確性を最優先する）。
- 将来この`国家総合職〈教養区分〉/`フォルダの内容を公開する場合は、その時点で著作権上の扱いを改めて厳格に見直す（`00_調査結果.md`§5、`人工知能/CLAUDE.md`の「公開する場合は別途再設計する」という既存の考え方を踏襲）。

## 4. 引用範囲

- 人事院公式資料からの引用は、出典を明記した上での要約・部分引用にとどめ、受験案内PDF等の全文転載は行わない。
- 二次情報（予備校サイト等）からの引用は、事実の裏付けが人事院一次資料で取れる場合のみ本文に反映し、二次情報のみを根拠とする断定的な記述は避ける。

## 5. 公開利用と個人利用の違い

現状は個人のローカル専用学習サイトであり、`.gitignore`対象・GitHub Pages非公開である（`00_調査結果.md`§5）。将来的にサイトを公開する場合は、次を追加で検討する必要がある：

- 過去問要約の著作権上の許容範囲の再確認（弁護士相談等も選択肢）
- 出典表示の見え方（利用者だけでなく一般公開時の第三者にも分かる形式）
- 予想問題が「公式見解」と誤解されないための、より強い注記

## 6. 出典の更新

`16_運用更新設計.md`の年度更新プロセスに従い、出典リンクの有効性・内容の変更有無を定期的に確認する。
