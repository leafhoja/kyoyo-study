# 用語定義（設計書内での統一）

## 1. この文書の目的

設計書全体・将来のサイトコンテンツで用語を統一するための定義集。制作者（複数のエージェント・セッションをまたぐ執筆者）が異なる意味で用語を使わないようにする。将来サイトに実装する「用語集」（04番§5.5、利用者向け）とは別に、**制作側の用語統一**を目的とする文書である。

## 2. 設計・運用に関する用語

| 用語 | 定義 |
|---|---|
| Level（0〜5） | 追加事項Cで定める問題の難易度段階。章本文の解説難易度（★基礎/★★標準/★★★発展）とは別軸。 |
| 閲覧完了 | 章本文の主要セクションを一度最後まで表示したこと。能力習得を意味しない最低限の完了条件。 |
| Level到達 | あるLevelの問題群について、一定の自力正解率等の基準を満たしたこと。 |
| 自力正解率 | ヒントを使わずに正解した割合。ヒント使用後の正解率と区別する。 |
| box-now | 年度・時点に依存する情報を隔離するためのコンポーネント。既存3サイト（金融・人工知能・株式ノート）由来の概念。 |
| 暫定版／レビュー済み／確定版 | 追加事項Aで定める文書・コンテンツの状態区分。 |
| 過去問 | 人事院により公式に出題された事実としての問題。 |
| 練習問題 | 制作者が知識確認・能力形成のために作成した問題（本番形式ではない）。 |
| 予想問題 | 制作者が根拠を明示して作成した、出題可能性のある問題（断定しない）。 |

## 3. 試験制度に関する用語（初出時に本文でも説明するが、制作側の統一のため定義しておく）

| 用語 | 定義 | 出典 |
|---|---|---|
| 国家総合職試験 | 中央省庁で政策の企画立案等に従事する職員を採用するための国家公務員試験。院卒者試験・大卒程度試験に分かれる。 | `00_調査結果.md` §4.1 |
| 教養区分 | 大卒程度試験の一区分。専門試験を課さず、総合論文試験・企画提案試験等で総合的判断力・企画力を測る区分。 | `00_調査結果.md` §4.1 |
| 基礎能力試験 | 第1次試験で課される多肢選択式試験。Ⅰ部（知能分野＋時事情報）・Ⅱ部（知識分野）からなる。 | `00_調査結果.md` §4.1 |
| 総合論文試験 | 第1次試験で課される記述式試験。教養・哲学的な考え方に基づく総合的判断力・論述力を測る。 | `00_調査結果.md` §4.1 |
| 企画提案試験 | 第2次試験で課される、資料を基にした政策提案・プレゼンテーションの試験。 | `00_調査結果.md` §4.1 |
| 政策課題討議試験 | 第2次試験で課される、グループ討議形式の試験。 | `00_調査結果.md` §4.1 |
| 人物試験 | 第2次試験で課される個別面接。 | `00_調査結果.md` §4.1 |
| 官庁訪問 | 最終合格者が採用候補者名簿に記載された後、各府省庁を訪問し採用者が決定されるプロセス。試験合格と採用は別。 | `00_調査結果.md` §4.1 |
| 採用候補者名簿 | 総合職試験合格者が得点順に記載される名簿（7年間有効）。 | `00_調査結果.md` §4.1 |

## 4. 用語の追加基準

新たに設計書・章コンテンツで繰り返し使う用語が出てきた場合、本文書に追加する。将来サイトに実装する利用者向け用語集（04番§5.5）とは別に、本文書は制作側の統一のためのものであることを維持する。
