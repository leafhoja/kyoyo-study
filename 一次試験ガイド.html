「飛ばす」と決めたら、何を残す？

  1. 問題冊子に△：あと一手、または候補を2つ程度に絞れた問題。消した選択肢や途中式も残す。
  2. 問題冊子に？：解法が浮かばない、必要な知識がない問題。見直しの優先順位を下げる。
  3. 再開するときは△から：残り時間内で正解まで進めそうな問題を選び、？の難問に戻る前に全体の未解答を確認する。

答案欄に仮の解答を入れる場合は、保留の記録を問題冊子側に残します。戻ったときは問題番号を再確認し、訂正するマークは消し切ること。答案用紙を自分用のメモとして使わないようにします。

優先順位難しい問題より「短時間で増やせる正解」

ある問題にさらに8分かければ解けそうでも、その8分で保留中の2問を確認できるなら、先に2問を見る選択ができます。同じ部では1正解の素点は同じなので、「ここまで時間をかけたから続ける」ではなく、「ここから何分で正解に近づくか」で決めます。

2巡目は「根拠のある迷い」を先に処理する

「2択まで絞った」「式は立ったが計算が残っている」「1つの記述を確かめれば決まる」という問題を優先します。2択なら、どちらのどの部分が本文・知識・計算と矛盾するかを比較。最初の直感だけを理由に、根拠のある解答を変更しないようにします。

たとえば一巡で8問を確保し、2択の問題が5問、判断材料がない問題が7問なら、まず5問の検証に時間を使います。この8問は合格を保証する数ではなく、次にどこへ時間を使うかを決めるための例です。試験中に正解数を確実に把握することはできないので、手応えだけで残りを放棄しないことが大切です。

総合論文：150分の使い方 当サイトの提案

設問を確認 → 資料を読む → 構成メモ → 執筆 → 推敲。2026年度は1題ですが、題中に複数の問いがある場合はすべての要求を確認し、指定字数・答案欄に合わせて配分します。

経過時間配分やること
0〜10分10分問い、資料、字数・形式の指定を確認。何に答えるかを書き出す
10〜35分25分資料の主張・根拠・対立点を整理。自分の意見と資料の内容を区別する
35〜50分15分結論・理由・具体例・反論への応答を構成メモにする。各問いに字数を割り当てる
50〜135分85分答案を執筆。すべての問いに答えることを優先して最後まで書く
135〜150分15分設問への答え漏れ、論理の飛躍、資料の誤読、字数、誤字を確認

構成メモに全文を書かず、段落ごとの要点にとどめます。残り30分で未着手の問いがある場合は、そこを優先。予定より遅れたら具体例や補足を短くし、結論と理由を完成させます。書く速度は総合論文の書き方の演習で実測してください。

最初の35分で、何を読み取る？

  1. 設問の動詞：「説明」「比較」「論じる」など、求められる作業を確認する。要約を求める問いに自分の意見だけを書かない。
  2. 資料の主張と根拠：筆者が何を結論とし、何を理由にしているかを分けてメモする。
  3. 対立する見方：両立しない前提や、重視する価値の違いを探す。単純な賛成・反対だけで整理しない。
  4. 自分の立場：資料のどの点を認め、どの条件では限界があると考えるかを決める。

資料から直接読み取ったことと、自分が追加する具体例を分けておくと、執筆時に根拠の出どころが曖昧になりにくくなります。問いが複数なら、読みながら「この根拠はどの問いに使うか」も整理します。

構成メモは、段落ごとに1〜2行

構成の例自分の考えを論じる問いの場合
  1. 結論：設問に対する自分の答えを短く示す。
  2. 理由：資料の主張や根拠を踏まえ、なぜそう考えるかを書く。
  3. 具体化：事例や条件を使い、主張がどの場面で成り立つかを説明する。
  4. 別の見方への応答：反論や限界を認め、そのうえで自分の判断を示す。
  5. まとめ：必要な条件を含めて結論を再確認する。

これは自分の意見を論じる場合の練習用の型です。資料の説明・比較を求める設問には、その要求に合う構成を使います。公式の採点基準を示したものではありません。

字数配分の例：仮に自分の意見を800字で論じる練習なら、結論80字・理由240字・具体例200字・反論への応答200字・まとめ80字で800字。実際の指定字数ではなく、段落の比重を考える例です。複数の問いがある場合は、まず問いごとの指定に従って配分します。

最後の15分で確認する順番

①すべての問いに答えたか → ②資料の主張を取り違えていないか → ③結論と理由がつながるか → ④字数・形式を守ったか → ⑤誤字・読みにくい訂正。言い回しの改善に時間を使う前に、答え漏れと論旨の矛盾を直します。大きく書き直すと完成が間に合わない場面では、必要な1〜2文の追加・訂正で修正できないかを考えましょう。

時間不足の立て直し方 当サイトの提案

途中の遅れは、残りの問題すべてを速く解こうとするより、着手する問題と確認時間を選び直して対処します。下表は標準配分案を使った場合の例です。

場面立て直し方残す時間
Ⅰ部：50分で文章理解が終わらない残りの文章問題を保留し、推理へ進む。文章の2択問題は最後の回収対象にする確認5分を固定し、保留回収15分の範囲で調整
Ⅰ部：残り40分で推理が多く残っている未着手を短く確認し、解法が見えるものから。重い場合分けは後回し。終了10分前を目安に全未解答を確認する最後5分は番号・マーク確認
Ⅱ部：25分で一巡できていないまだ見ていない問題を優先して、即答できる問題を探す。保留問題の再検討はその後にする最後5分は答案確認
Ⅱ部：残り10分で複数問が未解答選択肢を絞れる問題から処理し、判断材料がない問題に同じ時間を使わない検討5分＋確認5分
論文：50分を過ぎても構成に迷う設問への結論と主要な理由を決めて執筆へ移る。具体例を増やす検討はいったん止める推敲15分を基本に、遅れが大きければ最低10分を目安に確保
論文：残り30分で未着手の問いがある未着手の問いの結論・根拠を書くことを優先。書けている部分の補足や表現磨きは後にする残り10分までに全体を完成させ、答え漏れを点検

Ⅰ部終了後に出来を振り返りすぎると、Ⅱ部の集中を削ります。種目が切り替わったら、次の問題数・終了時刻・最初にすることを確認し直します。一次の手応えが悪くても、最終判定に使う総合論文は完成させましょう。

過去問で自分用の配分を作る 練習の手順

一度も測らずに時間配分だけ決めると、読む速度や計算速度と合わないことがあります。練習では解答開始からの経過時間を記録し、次のセットで少しずつ修正します。

  1. 最初は標準案で解く：解答・解説を閉じ、開始時刻と分野の切替時刻を記録する。途中で正解を見ない。
  2. 解答後に分類する：「時間内に自力で正解」「時間をかければ正解」「知識・解法が不足」「読み違い・計算・マークのミス」に分ける。
  3. 保留の効果を見る：長く粘って誤答した問題と、保留して最後に正解できた問題を比べる。粘る上限を見直す。
  4. 次回は5〜10分だけ調整：速く終わる分野から、時間があれば正解できる分野に移す。最後の確認時間は確保する。
記録の例（数値は架空の練習結果）

旧年度の過去問を組み直す例：Ⅰ部は旧Ⅰ部24問に、旧Ⅱ部から内容を確認して時事・情報6問を加え、30問・140分の練習セットにする。Ⅱ部は旧Ⅱ部の時事・情報を除く知識問題から20問を選び、60分で解く。選んだ問題番号を先に控え、未見の問題を優先します。これは時間管理の練習で、2026年度の難易度・出題比率を再現する模試ではありません。

論文も旧年度の2題を150分で解く練習にせず、教養・哲学的な考え方を扱う1題を選んで、構成・執筆・推敲の時間を測ります。本番に近い確認には2026年度の公式問題を併用してください。公式問題への入口は人事院・教養区分の案内の「参考」にあります。
